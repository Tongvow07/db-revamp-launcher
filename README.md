# DB Revamped Launcher

Self-updating Windows launcher for DB Revamped, a free, non-commercial fan project kept running for nostalgia and played for fun. It takes no payments and is not affiliated with or endorsed by the creators or rights holders of Dungeon Blitz, whose name, art, audio and characters belong to their respective owners.
UI is served live from the server (launcher/ui.js); this repo tracks launcher versions.

- `Play DB Revamped.bat` - run it (extract the whole folder first).
- Create an account, then Launch Game.
